# Security Policy

## Reporting a Vulnerability
If you discover a vulnerability in this repository content (for example, exposed secrets, unsafe instructions, or malicious dependencies in future additions), please report responsibly:

- Open a private security advisory if available, or
- Contact the maintainer directly through GitHub profile contact methods.

Please include:
- A clear description of the issue
- Reproduction steps (if applicable)
- Potential impact
- Suggested mitigation

## Scope
This repository is educational content. Do not perform unauthorized testing against systems you do not own or have explicit permission to assess.

- Basic computer networking knowledge
- Basic operating system familiarity (Windows/Linux)
- Comfort with terminal/command line

- CPU: 4+ cores recommended
- RAM: 16 GB minimum, 32 GB preferred
- Storage: 150 GB free space

## Accounts
- GitHub account
- Microsoft Azure account (free trial or subscription)

## Recommended Skills (Helpful, not mandatory)
- Basic scripting understanding
- Basic understanding of logs and troubleshooting

# Full Course Overview

This course is designed to provide a complete, hands-on cybersecurity training path for beginners and IT professionals moving into security roles.

## Delivery Modes
- **Azure Cloud Track**: Use cloud-native services and lab resources.
- **Local VMware Track**: Use virtual machines on your own workstation.

## Course Outcome
Learners will build practical SOC, incident response, vulnerability management, cloud IAM, and reporting capabilities aligned to junior cybersecurity role expectations.

## Completion Requirements
- Complete all module labs (Azure or VMware track, or both)
- Submit required artifacts and reports
- Score at least 70% on module quizzes
- Pass capstone incident response simulation

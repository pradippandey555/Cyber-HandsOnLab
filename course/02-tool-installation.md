# Tool Installation Guide

## Core Tools
- VMware Workstation Player/Pro (or equivalent)
- Kali Linux VM image (or security distro)
- Ubuntu Server/Desktop VM image
- Windows evaluation VM image (for AD/SOC scenarios)
- Wireshark
- Nmap
- Nessus Essentials / OpenVAS (where applicable)
- Sysmon + log shipping agent (for SOC modules)

## Documentation Tools
- Markdown editor
- Screenshot utility
- Spreadsheet tool for risk registers and timelines

## Validation
After installation:
1. Confirm all VMs boot.
2. Confirm isolated lab network is working.
3. Confirm logs can be generated and reviewed.

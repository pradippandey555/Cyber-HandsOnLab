# Contributing to Cyber-HandsOnLab

Thank you for your interest in improving this cybersecurity learning repository.

## How to Contribute
1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Submit a pull request with a clear summary and rationale.

## Contribution Types
- Improve module instructions and lab quality.
- Add detection/use-case examples.
- Fix typos, broken links, and clarity issues.
- Add report templates and validation checklists.

## Content Standards
- Keep all activities ethical and legal.
- Use beginner-friendly language.
- Include measurable outcomes and deliverables.
- Avoid unsafe guidance for real-world unauthorized testing.

## Pull Request Checklist
- [ ] Clear title and description
- [ ] Scope and module impacted listed
- [ ] Screenshots/log evidence when relevant
- [ ] No sensitive data or secrets included

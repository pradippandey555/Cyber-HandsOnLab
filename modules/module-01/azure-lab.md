# Module 01 - Azure Lab

## Objective
Perform safe reconnaissance activities against approved lab assets in Azure.

## Tasks
1. Create a lab target inventory from your Azure resources.
2. Collect passive metadata (DNS, IP ranges, service banners where allowed).
3. Perform controlled active recon on explicitly approved targets.
4. Document exposed services and potential risks.

## Evidence
- Target list
- Recon command output/screenshots
- Findings matrix

## Deliverable
- Recon technical report and executive summary.

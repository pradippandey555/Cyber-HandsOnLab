# Module 01 - VMware Lab

## Objective
Perform safe reconnaissance in an isolated local VM environment.

## Tasks
1. Build a local target list (VM IPs, hostnames, roles).
2. Execute passive info collection from local inventories.
3. Perform safe active reconnaissance in lab-only network.
4. Record attack surface observations.

## Evidence
- Local network map
- Recon outputs
- Risk-ranked findings

## Deliverable
- Recon report with scope and methodology.
